Entry for the [Make the AI Judge Laugh: Cat Reviews Its Human](https://make.fun/c/u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990) competition on [make.fun](https://make.fun).

`main.py` writes one funny single-line one-star review, written by a house cat about its human, to `/output/entry.txt`.

## The review

> One star. He refills my bowl, then stands there waiting for gratitude like a waiter expecting a tip. I tipped the bowl instead.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
